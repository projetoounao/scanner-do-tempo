# Acervo visual e audiovisual — leitura pública e futura galeria

O Scanner do Tempo pretende relacionar **fotografias históricas, registros de eventos, documentos digitalizados, desenhos, imagens de observação e vídeos** com fontes, datas, locais e pessoas documentadas. Esta seção será o ponto de entrada para uma futura galeria vinculada ao QR code do livro.

**Estado em 14/10/2026:** foram identificados arquivos candidatos nas pastas de pesquisa do Google Drive, mas **as cópias ainda não estão publicadas aqui**. Ter um arquivo em uma pasta de trabalho não demonstra licença de republicação. O objetivo é permitir incluir todo o material **que possa ser difundido legitimamente**, sem retirar a procedência dos originais.

## Organização recomendada quando houver liberações

```text
    capsula-2018/
    paisagens-e-observacao/
  documentos/
  ilustracoes-e-projetos/
  animacoes/
  videos/
  fichas/
```

Os nomes acima são uma proposta de organização, não diretórios contendo arquivos já disponibilizados. Quando publicados, os arquivos devem ter ficha de procedência, autoria, evento, data, lugar, licença, restrições e vínculo com o livro. A fotografia pode ter uma versão leve para visualização e um original-mestre mantido sob custódia apropriada.

## Imagens, vídeos e limites técnicos

O GitHub pode apresentar fotos e arquivos multimídia autorizados, mas nem sempre é o melhor depósito para **originais muito grandes** ou arquivos de preservação de décadas. Para vídeo longo, utilizar armazenamento/serviço de mídia apropriado e inserir aqui uma ficha e endereço estável; para determinados arquivos de distribuição, avaliar GitHub Releases ou Git LFS sem tornar o repositório gigantesco. O GitHub **não será o único backup ou a reserva técnica do Museu**.

A abertura pública de fotografias com participantes, crianças, documentos manuscritos e informações pessoais requer avaliação específica de direito de imagem, autoria, privacidade e finalidade. **Nenhuma dessas pendências implica que o material não possa vir a ser publicado** — apenas que a publicação deve ser deliberada e documentada.
