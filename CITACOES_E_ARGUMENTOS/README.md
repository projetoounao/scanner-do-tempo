# Citações e argumentos

Esta seção organiza citações candidatas, paráfrases, referências e sua **função no argumento** do Scanner do Tempo.

A finalidade não é colecionar frases de efeito. Cada citação deve responder a uma necessidade do texto ou da pesquisa.

## Funções possíveis

- **EPÍGRAFE** — abertura e enquadramento;
- **DEFINIÇÃO** — delimitação conceitual;
- **EVIDÊNCIA** — sustentação documental;
- **TESTEMUNHO** — voz situada de participante ou autor;
- **CONTEXTO** — enquadramento histórico ou territorial;
- **VOZ LOCAL** — formulação produzida por autores ligados a Cuité;
- **CONTRAPONTO** — tensão ou limite;
- **TRANSIÇÃO** — passagem entre núcleos argumentativos;
- **PROVOCAÇÃO** — pergunta ou formulação que abre investigação.

## Estatutos

Quando necessário, os registros podem ser marcados como:

- **[D] Documental** — sustentado por fonte identificada;
- **[R] Reflexão** — interpretação autoral;
- **[H] Hipótese** — possibilidade em investigação;
- **[Q] Questão** — problema aberto.

## Matriz mínima

Cada citação ou paráfrase deve registrar:

| Campo | Conteúdo |
|---|---|
| ID | identificador |
| Autor | autoria |
| Fonte | obra/documento |
| Página | página ou localização |
| Trecho | apenas o necessário |
| Tema | assunto principal |
| Argumento | o que sustenta |
| Função | epígrafe, evidência etc. |
| Estatuto | D/R/H/Q, se pertinente |
| Verificação | conferida / a conferir |
| Uso público | permitido / condicionado / a verificar |

## Direitos autorais

O repositório público deverá privilegiar **trechos curtos, paráfrases e referências completas**. Textos extensos não serão reproduzidos apenas por estarem disponíveis em uma fonte consultada.

No caso de Jorge Luis Borges, a epígrafe usada nos ensaios deve permanecer vinculada à edição e tradução efetivamente utilizadas, mas o repositório não precisa reproduzir o trecho integral em todas as páginas.
